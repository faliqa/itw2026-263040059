Belajar CSS Selector

Selector digunakan untuk memilih elemen HTML yang ingin diberi gaya.

Contoh selector

Selector elemen: aturan h1 memberi gaya pada semua elemen judul tingkat satu.

Selector class: aturan .pengantar memilih elemen dengan class pengantar.

Selector ID: aturan #judul-contoh memilih elemen dengan ID judul-contoh.

Selector turunan: aturan .kartu p memilih paragraf di dalam elemen kartu.
